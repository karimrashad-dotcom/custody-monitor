# منصة مراقبة العهد والمصاريف

برنامج ويب بيفتح على الموبايل: الموظفين أصحاب العهد بيصوّروا الفواتير ويرفعوها، والبرنامج بيقرا بياناتها،
وينبّه المدير لو فاتورة عدّت الحد أو اتكررت، ويقفل العهدة أسبوعياً، ويطلع أرخص مورد لكل صنف أو نوع مصروف.

## التشغيل على اللاب (Windows)

1. نزّل Python 3.12 من [python.org](https://www.python.org/downloads/) ووقت التثبيت علّم على **Add python.exe to PATH**.
2. نزّل الكود (زرار **Code ← Download ZIP** على GitHub) وفكّه في فولدر، مثلاً `C:\custody-monitor`.
3. دبل كليك على `start.bat`. أول مرة بياخد كام دقيقة عشان ينزّل المكتبات.
4. افتح `http://localhost:8000` واعمل حساب المدير.
5. الموبايلات اللي على نفس الواي فاي تفتح العنوان اللي بيظهر في الشاشة السودا، زي `http://192.168.1.20:8000`.
   لو مفتحش، اسمح للبرنامج في Windows Firewall (بيسأل أول مرة، اختار Private networks).

البيانات كلها (القاعدة وصور الفواتير) في فولدر `data`. النسخة الاحتياطية = نسخ الفولدر ده.

## القراءة الذكية

- **QR**: الفواتير الإلكترونية السعودية فيها كود QR بيتقري مجاناً ومن غير نت (المورد، الرقم الضريبي، التاريخ، الإجمالي، الضريبة).
- **Claude**: لو حطيت مفتاح API في **الإعدادات**، البرنامج بيقرا كمان رقم الفاتورة والأصناف والتصنيف، وبيقرا الفواتير اللي مفيهاش QR.
- الموظف دايماً بيراجع البيانات ويعدّلها قبل ما يبعت.

## التنبيهات

بتظهر في صفحة **التنبيهات** عند المدير في الحالات دي:
- الفاتورة أكبر من حد الفاتورة الواحدة للعهدة (الحد بيتقارن بالإجمالي شامل الضريبة).
- الفاتورة مكررة (نفس الرقم ونفس المورد، أو نفس الصورة).
- مصروف الأسبوع عدّى مبلغ العهدة.
- الموظف رفع كشف العهدة.

وممكن توصل إيميل كمان لو ظبطت بيانات SMTP في الإعدادات.

## الإقفال الأسبوعي

كل عهدة ليها أسبوع مفتوح (بيبدأ الأحد افتراضياً، وده بيتغير من الإعدادات). المدير بيعتمد أو يرفض الفواتير،
وبعدين يقفل الأسبوع من صفحته. الإقفال بيطلع ملخص وملف Excel، وأول فاتورة بعده بتفتح أسبوع جديد بمبلغ العهدة كامل.

## التشغيل على سيرفر الشركة

بـ Docker:

```sh
docker compose up -d --build
```

أو على Windows Server بنفس طريقة اللاب (`start.bat`). انقل فولدر `data` من اللاب للسيرفر عشان البيانات تنتقل.
لو البرنامج هيتفتح من برا شبكة الشركة، حطه ورا HTTPS (مثلاً IIS أو nginx أو Caddy).

## للمطورين

```sh
pip install -r requirements.txt pytest httpx
python -m pytest -q tests
python -m uvicorn app.main:app --reload
```

- `app/main.py`: الصفحات والمسارات
- `app/db.py`: قاعدة البيانات SQLite
- `app/extract.py`: قراءة QR وClaude
- `app/alerts.py`: الفحوصات والتنبيهات
